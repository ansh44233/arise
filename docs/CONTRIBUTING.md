# Contributing to Arise

Thank you for your interest in contributing! 🎉

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/arise`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make changes and commit
5. Push and open a PR

## Code Style

- Use ESLint config provided
- Prettier for formatting (`npm run format`)
- Meaningful commit messages

## Commit Format

```
type(scope): subject

feat(voice): add noise cancellation
fix(socket): prevent disconnect loop on navigation
docs(readme): update deployment section
```

## Review Process

All PRs are reviewed within 48 hours. After approval, maintainer will merge.

## Questions?

Open a Discussion in the GitHub Discussions tab!
